    47. Other challengers and software-defined players¶

    Depth: L2 · Reading time: ~10 min · Last verified: 2026-11-01 Prerequisites: File protocols · Object storage and S3 · Software-defined storage and HCI · Incumbents

    TL;DR¶

    • The biggest challenger is the hyperscalers' own storage. S3 alone holds over 500 trillion objects; cloud-born data rarely goes out to bid.
    • Hammerspace is the most strategic of the smaller players. Its pNFS global namespace sits above everyone's arrays, and "Tier 0" turns idle GPU-server NVMe into shared storage. If it wins, arrays become interchangeable.
    • Open-source object broke in 2025–2026. MinIO gutted its free edition and archived the repository in April 2026, pushing users to paid AIStor, Ceph, forks or supported S3 from other vendors.
    • Software-defined and platform vendors win on control and cost, not peak speed. Ceph, Lightbits and Nutanix suit buyers who want to own hardware or leave VMware; Nutanix is also an Everpure partner.
    • Qumulo, Cloudian, VDURA and Lenovo-owned Infinidat are niche threats. Each has a defensible base and caps Everpure's share in one segment.

    Why this matters for Everpure strategy¶

    VAST, WEKA and DDN (Chapters 42–45) and the incumbents (Chapter 46) get the attention, but much of the pressure on Everpure's (NYSE: P, formerly PSTG) margin comes from layers it does not control. Hammerspace and the hyperscalers compete for the namespace and control plane above the array. Ceph, MinIO and Lightbits put software on commodity servers, which caps what buyers will pay for an integrated system. Nutanix competes for the platform that VMware-exit budgets fund. Each tests Everpure's claim that integrated hardware plus Purity and Evergreen beats assembling parts. Most are also private, sub-scale or newly acquired: possible targets, partners or channels (Chapter 54).

    Hammerspace: a namespace over everyone's storage¶

    Hammerspace separates where a file appears from where its bytes live. Metadata servers (Anvil) hold one global namespace. Data-services nodes (DSX) and existing NFS, object or cloud storage hold the bytes1. Clients run the stock Linux NFSv4.2 client with the pNFS Flex Files layout: they get a layout from the metadata server, then do I/O directly against storage nodes (Chapter 8). Policies ("objectives") move open files between tiers and sites; only the layout changes.

    Semiconductor bridge. This is virtual memory for files. The namespace is the page table; moving data is migrating a page from DRAM to CXL memory while the application keeps its address. The moat is that the "MMU" lives in the Linux kernel: CTO Trond Myklebust maintains the upstream Linux NFS client2.

    Tier 0. Launched in November 2024, Tier 0 pools the local NVMe inside GPU servers into a shared, protected tier of the same namespace3. Protection is client-side mirroring across availability zones; client-side erasure coding is roadmap4. Version 5.2 added "affinitization", which writes a client's data to its own local Tier 0 volume5.

    Worked example (illustrative). Take 1,000 GPU servers with eight 3.84 TB NVMe drives each, a common DGX-class configuration: 1,000 × 8 × 3.84 TB ≈ 30.7 PB raw, already paid for, or about 15 PB mirrored. At about 6 GB/s per Gen4 drive, aggregate local bandwidth is 1,000 × 8 × 6 ≈ 48 TB/s, far more than any shared array. The catches: reboots take drives offline, mirror traffic shares the GPU network, and capacity follows the server refresh cycle. So Tier 0 suits checkpoints and scratch, later drained to a shared tier (Chapter 31).

    Why it has customers. Meta is the flagship. Its two 24,576-GPU GenAI clusters used parallel NFS co-developed with Hammerspace, alongside Tectonic6. In April 2025 Hammerspace raised a US$100M Series B led by Altimeter, at a valuation above US$500M (reported by press), and talked of an IPO within about two years7. Weak spots: no NVIDIA SuperPOD or NVIDIA-Certified Storage designation8, and performance bounded by the storage underneath.

    Qumulo and VDURA: file specialists that changed their business model¶

    Qumulo sells a scale-out NAS with real-time capacity and activity analytics, popular in media, life sciences and research. Under CEO Doug Gourlay (from July 2024) it moved from its own hardware to software for cloud, on-premises and edge9. Its distinctive asset is Azure Native Qumulo, a file service sold and billed inside Azure. In June 2026 it added tooling to migrate legacy NAS data into it10. Its last priced round was a US$125M Series E at US$1.2B in July 2020 (company-stated)11 [VERIFY: Qumulo funding since 2020]. Customers buy simplicity and file analytics, not peak GPU throughput.

    VDURA is Panasas, rebranded in May 2024 as a software-first company12. In 2025 it relaunched PanFS as an AI/HPC platform aimed at VAST, WEKA and DDN, with a V5000 all-flash appliance and, from March 2026, hybrid flash-plus-disk options13. It claims one of the largest defense GPU installations (company-stated)14. It offers lab-proven PanFS and disk economics while flash is dear; its risk is scale [VERIFY: VDURA funding].

    MinIO: the open-source object store that closed itself¶

    MinIO, a single fast, free binary, became the default S3-compatible store for developers, Kubernetes and many neoclouds. It raised US$103M at a US$1B valuation in January 2022, led by Intel Capital15. Then it withdrew the community edition in stages:

    1. June 2025: the admin console was removed, leaving a basic object browser; administration moved to the CLI or paid AIStor16.
    2. Late 2025: official binaries and images stopped updating, reportedly in October 2025; the README now says the community edition ships as source code only. On 3 December 2025 the project entered maintenance mode, with security fixes only case by case17.
    3. 2026: the README was changed to say the repository is no longer maintained (12 February, per a fork maintainer's account19). GitHub shows minio/minio archived on 25 April 2026. The AGPLv3 source remains readable, and the README points to AIStor Free and AIStor Enterprise18.

    Semiconductor bridge: a licensor changing terms after an ecosystem standardized on its architecture. Licensees pay, fork19 or port, here to Ceph RGW or commercial S3.

    AIStor itself is serious: it shipped S3 over RDMA in November 202420, and MinIO is an NVIDIA STX partner21. Worked example: a neocloud migrating 50 PB off community MinIO at a sustained 100 GB/s needs 50 × 10¹⁵ ÷ 10¹¹ = 500,000 s ≈ 5.8 days of saturated copying. With verification and cut-over it takes weeks, so many will simply pay MinIO.

    Cloudian and Ceph: object for people who want control¶

    Cloudian HyperStore is S3-native object storage, sold as software, appliances or via HPE GreenLake, strong with regulated on-premises buyers. In June 2024 it raised US$23M of growth financing from Morgan Stanley Expansion Capital, citing 30% ARR growth, breakeven and about US$256M raised in total (company-stated)22. It was early to GPUDirect for object (200+ GB/s claimed, November 2024)23. Its HyperScale AI Data Platform adds in-storage vector search24; HyperStore 8.2.6 became NVIDIA-Certified (Foundation) in March 202625.

    Ceph is the Linux of storage: one open-source system for block (RBD), file (CephFS) and object (RGW), free as code and costly to run well. Clyso tuned a 68-node NVMe cluster past 1 TiB/s26, showing both the ceiling and the skill required. It is commercialized three ways:

    • IBM Storage Ceph, inherited from Red Hat, with release 9.0 in January 202627.
    • Software and support specialists, Croit (management software and support)28 and Clyso (engineering and consulting)26.
    • Hardware integrators such as 45Drives, which ships servers with its Houston management UI for Ceph deployment29.

    Think RISC-V: the ISA is free; value goes to whoever makes it reliable for telcos, universities, sovereign clouds and neoclouds.

    Block and platform: Lightbits, Infinidat, Nutanix¶

    Lightbits sells software-defined block storage over NVMe/TCP, a standard it helped create (Chapter 7). Crusoe's AI-cloud block service runs on it at multi-petabyte scale3031. Last disclosed funding was US$42M in 2022 (US$105.3M total)32. Neoclouds use it to build EBS-like services.

    Infinidat builds InfiniBox, a high-end block array serving most reads from DRAM in front of large HDD or flash pools. Lenovo announced the purchase in January 2025 and closed it in April 2026; Infinidat is now a unit of Lenovo's Infrastructure Solutions Group33. Calcalist estimated the undisclosed price at over US$500M (estimated)34. The gain is Lenovo's distribution.

    Nutanix sells a platform: Nutanix Unified Storage (Files, Objects, Volumes) alongside the AHV hypervisor and NKP, its Kubernetes platform built from the D2iQ acquisition (2024)35. Broadcom's VMware licensing changes are the tailwind. Nutanix reported more than 1,000 new logos in fiscal Q2 2026, its best in eight years, mostly ex-VMware [VERIFY: search-summary only]36, and fiscal 2026 ARR of US$2.55B, up 16%37. AHV now also accepts external arrays: Dell PowerFlex, Pure Storage FlashArray over NVMe/TCP (May 2025), then NetApp ONTAP and Dell PowerStore3839. NUS also became NVIDIA-Certified in 202640.

    The biggest challenger: hyperscaler-native storage¶

    Each hyperscaler sells a full menu: AWS S3, EBS and FSx (Lustre, NetApp ONTAP, OpenZFS, Windows); Azure Blob, Azure NetApp Files and Azure Managed Lustre; Google Cloud Storage and Managed Lustre. S3 alone holds more than 500 trillion objects and serves more than 200 million requests per second across hundreds of exabytes41. S3 Vectors (GA December 2025) shows them moving up the stack42.

    The parallel is custom silicon: Graviton, Trainium and TPU did not beat merchant chips everywhere, but took the workloads already in the cloud. Clouds also rent partner technology as first-party services when that is faster than building. Google Cloud Managed Lustre runs on DDN EXAScaler and went GA in July 202543, and NetApp's first-party and marketplace cloud storage revenue grew 27% in fiscal Q3 202644. And they compete on AI performance: Azure Managed Lustre was the first hyperscale cloud service in MLPerf Storage, at 642.2 GiB/s checkpoint write in v3.045. Google's DAOS-based Parallelstore is reportedly being phased out for Managed Lustre [VERIFY: partner source only]46.

    Against hyperscalers, Everpure puts Purity in the cloud: Pure Storage Cloud Azure Native is a jointly developed managed Azure service47. Its second top-five-hyperscaler DirectFlash design win (August 2026) makes a hyperscaler a customer48. The steelman is NetApp, whose ONTAP is first-party on all three clouds; Everpure has no AWS or Google equivalent. Against Hammerspace, FlashBlade//EXA uses the same pNFS idea with Everpure's own metadata engine. Is Hammerspace a partner over FlashBlade, or a layer that commoditizes it? Against Ceph, MinIO and Lightbits, it sells simplicity and Evergreen against "free plus engineers", winning where staff are scarce. With Nutanix, Everpure wins when VMware exits land on AHV with FlashArray.

    Conversation playbook¶

    Questions for a PM

    1. "When a customer runs Hammerspace over FlashBlade, who owns the account?" Strong: separates namespace from capacity and says what EXA adds.
    2. "How many MinIO community users have we converted since December 2025, and with what?" Strong: FlashBlade or FlashArray S3, typical size, the rival Ceph or AIStor quote.
    3. "What share of Nutanix AHV migrations attach FlashArray rather than Nutanix storage?" Strong: an attach rate and how Nutanix sellers are paid.

    Questions for an engineer

    1. "What does Tier 0 lose if a GPU server reboots mid-checkpoint, and how does EXA handle that failure?" Strong: mirror placement, rebuild traffic on the GPU fabric, draining.
    2. "Where is our S3 slower than Ceph RGW or AIStor on small objects, and why?" Strong: a measured objects-per-second figure and the metadata-path reason (Chapter 18).
    3. "Could Purity run as a first-party service on AWS, as ONTAP does in FSx?" Strong: separates the engineering gap (control plane, multi-tenancy, billing) from the commercial one.

    Don't say this:

    • "MinIO is dead." The community repository is archived; AIStor is sold and NVIDIA-partnered.
    • "Hammerspace is an array competitor." It is a namespace layer that can sit on top of Everpure.
    • "Ceph is free." The code is; running it at scale costs engineers, which is what Everpure sells against.
    • "Nutanix is just a competitor." Since May 2025 it is also a FlashArray route to market.
    • "The cloud is just another competitor." It is the default home for new data.

    Key terms¶

    • Global namespace — one file tree spanning many systems and sites.
    • Tier 0 — Hammerspace's shared tier built from GPU servers' local NVMe.
    • pNFS Flex Files — NFSv4.2 layout for direct client I/O to data servers.
    • AIStor — MinIO's commercial object store.
    • Open-core relicensing — shrinking a free edition to push users to paid ones.
    • Ceph RGW / RBD / CephFS — Ceph's object, block and file interfaces.
    • NVMe/TCP — NVMe over ordinary TCP/IP Ethernet.
    • First-party cloud storage service — partner storage sold and billed by the cloud as its own.
