- **Block protocol** — A protocol that lets a host read and write numbered fixed-size blocks on a remote device, with no notion of files. | 7
- **Initiator** — The host side of a block-storage session that issues read and write commands. | 7
- **Target** — The device or array side of a block-storage session that executes commands from initiators. | 7
- **SCSI** — The Small Computer System Interface command set, standardized in 1986 and still carried over Fibre Channel and iSCSI. | 7
- **LUN (logical unit number)** — The SCSI address of a block volume presented by a target. | 7
- **Fibre Channel (FC)** — A dedicated, lossless storage network using credit-based flow control, the traditional enterprise SAN fabric. | 7
- **Buffer-to-buffer credits** — Fibre Channel's flow-control scheme, in which a sender transmits only as many frames as the receiver has buffers for, so frames are never dropped for congestion. | 7
- **Zoning** — A Fibre Channel switch-level access-control list defining which hosts can see which storage ports. | 7
- **iSCSI** — SCSI commands carried over TCP/IP on ordinary Ethernet (IETF RFC 3720, 2004). | 7
- **NVMe** — A storage interface and command set designed for flash on PCIe, built around many parallel submission and completion queues. | 7
- **Namespace** — The NVMe equivalent of a LUN, an addressable block volume exposed by an NVMe controller. | 7
- **Submission queue / completion queue (SQ/CQ)** — NVMe's paired rings in host memory holding 64-byte commands and 16-byte completions. | 7
- **Doorbell register** — A device register that the host writes to tell an NVMe controller that new queue entries are ready or have been consumed. | 7
- **NVMe over Fabrics (NVMe-oF)** — The extension of NVMe across a network, using command and response capsules over RDMA, Fibre Channel or TCP. | 7
- **Capsule** — An NVMe-oF message carrying a command or a response, and optionally in-line data. | 7
- **NVMe/TCP** — The NVMe-oF transport that carries capsules and data on ordinary TCP connections, ratified in 2018. | 7
- **FC-NVMe (NVMe/FC)** — The NVMe-oF transport that carries NVMe over Fibre Channel, standardized by INCITS T11 in 2017. | 7
- **NVMe/RoCE** — NVMe-oF over RDMA on converged Ethernet, in which the target moves data directly to or from host memory without CPU copies. | 7
- **ANA (Asymmetric Namespace Access)** — NVMe's multipathing mechanism that reports which paths to a namespace are optimized, the counterpart of SCSI ALUA. | 7
- **R2T (Ready to Transfer)** — A target's message inviting the host to send write data, used in iSCSI and NVMe/TCP. | 7
- **NQN (NVMe Qualified Name)** — The unique name identifying an NVMe host or subsystem for discovery and access control. | 7
