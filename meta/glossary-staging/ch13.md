- **Storage stack** — The ordered layers an I/O crosses from application to physical media: application, file system or object API, volume manager, protocol, network, array controller software, SSD controller/FTL and media. | 13
- **Data services** — The "intelligence" of a storage system: data placement, protection, data reduction and metadata management. | 13
- **Volume manager** — Host or hypervisor software that pools and remaps block addresses across devices, such as LVM or software RAID. | 13
- **Array controller software** — The operating environment of a storage system (e.g., Purity, ONTAP) that runs placement, RAID or erasure coding, snapshots, replication and data reduction. | 13
- **Persistence point** — The layer at which a write is durable enough for the system to acknowledge it, typically mirrored NVRAM in an array or power-loss-protected DRAM in an SSD. | 13
- **NVRAM** — Non-volatile memory in a storage controller that holds acknowledged writes until they are written to flash, surviving power loss. | 13
- **Power-loss protection (PLP)** — Capacitors in an enterprise SSD that let it flush its DRAM write buffer to NAND if power fails, so it can acknowledge writes from DRAM. | 13
- **DAS (direct-attached storage)** — Storage inside or cabled directly to one server, with no storage network in between. | 13
- **SAN (storage area network)** — A dedicated network giving many hosts block-level access to shared arrays. | 13
- **NAS (network-attached storage)** — A storage system that owns the file system and serves files to hosts over NFS or SMB. | 13
- **Vertical integration (storage)** — Owning several adjacent stack layers, for example array software, flash translation and module design, as one engineered product. | 13
- **Software-only storage** — Storage software sold to run on customer- or partner-supplied commodity servers rather than as a vendor appliance. | 13
- **FTL mapping DRAM** — The DRAM an SSD uses to hold its logical-to-physical page map, roughly 1 GB per TB of flash at 4 KB granularity. | 13
