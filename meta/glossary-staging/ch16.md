- **DASE (disaggregated shared-everything)** — A storage architecture in which stateless compute nodes share access to all media in separate enclosures over an NVMe-oF fabric, so no node owns any data. | 16
- **CNode** — VAST's stateless compute node that runs protocols, data reduction and erasure coding but holds no authoritative state. | 16
- **DNode** — VAST's enclosure fabric endpoint (often a DPU) that exposes an enclosure's SSDs to the NVMe-oF fabric. | 16
- **DBox** — VAST's storage enclosure holding SCM and QLC SSDs behind redundant DNodes. | 16
- **CBox** — VAST's server chassis containing multiple CNodes. | 16
- **EBox** — VAST's packaging that runs CNode and DNode software on the same server, trading independent scaling for hyperscaler and cloud fit. | 16
- **Storage-class memory (SCM)** — Persistent media much faster and more durable than QLC NAND (e.g., Optane or SLC-based SSDs), used as a write buffer and metadata store. | 16
- **Write buffer** — A small persistent tier that absorbs and acknowledges writes before they are reorganized and written to capacity media. | 16
- **Migration (SCM-to-QLC)** — The background process that reduces buffered data and writes it to QLC flash in large erasure-coded stripes. | 16
- **Locally decodable code** — An erasure code that can rebuild a lost strip by reading only a subset of the stripe, cutting rebuild I/O. | 16
- **Stripe width** — The number of data plus parity strips in one erasure-coded stripe, e.g., 146+4; wider stripes mean lower capacity overhead. | 16
- **DBox-HA** — VAST's option that limits strips per enclosure so a cluster survives the loss of an entire DBox. | 16
- **Enclosure blast radius** — The amount of data and service affected when an entire storage enclosure fails. | 16
- **Back-end fabric** — The network that connects storage compute nodes to storage media, separate from the front-end network clients use. | 16
- **Fabric amplification** — The ratio of back-end network traffic to client traffic, raised by mirroring and data migration. | 16
- **Storage Availability Zone (SAZ)** — NetApp AFX's single shared pool of NVMe shelves that every controller can read and write. | 16
- **SEDA** — HPE's name for the shared-everything disaggregated architecture of its Alletra MP X10000. | 16
- **Metadata/data split** — A design that scales metadata servers separately from data nodes, with clients reading data nodes directly, as in pNFS or Lustre. | 16
- **Purity//DN** — Everpure's data-node software for FlashBlade//EXA, running on off-the-shelf servers. | 16
