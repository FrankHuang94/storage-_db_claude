- **Object gateway** — A stateless server that terminates S3 requests, checks authentication and policy, and reads or writes object fragments on behalf of clients. | 18
- **Metadata index (object store)** — The replicated, sharded table that maps each bucket, key and version to an object's size, ETag and fragment locations. | 18
- **Erasure set** — A fixed group of drives (2–16 in MinIO) across which one object's data and parity fragments are always written. | 18
- **Inline object** — A small object whose bytes are stored inside its metadata record instead of being erasure-coded into separate fragments. | 18
- **Bucket index sharding** — Splitting one bucket's key index into multiple shards so that writes and LIST requests spread across servers. | 18
- **Dynamic resharding** — Automatically increasing a bucket index's shard count as the object count grows, as Ceph RGW does above a per-shard threshold. | 18
- **Geo-distributed erasure coding** — Spreading an erasure-coded stripe across several sites so the loss of a whole site is survivable at lower capacity overhead than replication. | 18
- **Hedged read** — Requesting more fragments or replicas than needed and using the first to arrive, to cut tail latency. | 18
- **Write quorum** — The minimum number of fragment or replica writes that must succeed before a write is treated as durable. | 18
- **Scrubbing** — A background process that re-reads stored data and verifies checksums to find and repair silent corruption (bit rot). | 18
- **Lifecycle policy** — A rule that automatically expires, deletes old versions of, or moves objects to another tier after a set age or condition. | 18
- **ShardStore** — The key-value storage-node engine, written in Rust, that stores object shards on each Amazon S3 storage node. | 18
- **ILM (information lifecycle management)** — NetApp StorageGRID's rule engine that decides where and how (replicated or erasure-coded) each object is stored over time. | 18
- **Chunk (object store)** — A large fixed-size container (128 MB in Dell ObjectScale) into which many objects are packed before erasure coding. | 18
