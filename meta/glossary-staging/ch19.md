- **Software-defined storage (SDS)** — Storage software sold separately from the hardware it runs on, deployed on commodity servers. | 19
- **Hyperconverged infrastructure (HCI)** — An architecture in which every cluster node runs applications (usually VMs), storage software and local drives together. | 19
- **Hardware compatibility list (HCL)** — The vendor-published list of servers, drives, NICs and firmware versions that software-defined storage is supported on. | 19
- **Stranded resources** — Compute or capacity that is bought only because a fixed node configuration bundles it with the resource actually needed. | 19
- **Controller VM (CVM)** — Nutanix's per-node virtual machine that runs the storage service in an HCI cluster. | 19
- **vSAN** — VMware's HCI storage software, which runs inside the ESXi hypervisor kernel and pools node-local drives. | 19
- **vSAN Max** — A VMware deployment model that builds a storage-only vSAN cluster mounted by separate compute clusters. | 19
- **VMware Cloud Foundation (VCF)** — Broadcom's main VMware subscription bundle, licensed per core, combining vSphere, vSAN, NSX and management tools. | 19
- **Storage-only node** — An HCI node that contributes capacity but runs no application VMs, used to break coupled scaling. | 19
- **Chain replication** — A replication scheme in which writes flow along an ordered chain of servers (primary to replica) and are acknowledged once the chain has persisted them. | 19
- **Configuration master** — A separate service that records which servers form each replication chain and changes membership after failures. | 19
- **Physalia** — AWS's configuration-master store for EBS, giving each volume its own small Paxos-replicated cell. | 19
- **Nitro card** — AWS's custom offload card that, among other jobs, presents EBS volumes to guests as NVMe devices and sends I/O over the network. | 19
- **Scalable Reliable Datagram (SRD)** — AWS's multipath, reliable but out-of-order transport implemented in Nitro cards and used by EBS io2 Block Express. | 19
- **io2 Block Express** — AWS's highest-performance EBS volume type, built on a re-architected back end reached over SRD. | 19
- **Re-mirroring storm** — A cascade in which many volumes lose replicas at once and their simultaneous repair traffic exhausts capacity and network. | 19
- **AGPLv3** — A copyleft open-source licence that requires sharing source code even when software is offered over a network. | 19
- **Gemini (VAST)** — VAST Data's model in which customers buy certified hardware at cost from a partner and pay VAST a software subscription. | 19
