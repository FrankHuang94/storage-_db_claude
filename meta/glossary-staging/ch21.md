- **Metadata** — Data about stored data: names, directory structure, permissions, sizes, timestamps and the maps from file offsets to physical blocks. | 21
- **Namespace** — The tree of directory and file names that a file system presents to clients. | 21
- **Inode** — A per-file record holding a file's attributes (owner, permissions, size, timestamps) and pointers to where its data lives. | 21
- **Dentry (directory entry)** — A record inside a directory that maps a file or subdirectory name to its inode number. | 21
- **Extent** — A contiguous run of physical blocks described by a single map entry, replacing many per-block pointers. | 21
- **Metadata server (MDS)** — The server or service that owns namespace and inode operations in a file system whose data lives elsewhere. | 21
- **Metadata storm** — A burst of creates, opens or stats, such as thousands of ranks writing checkpoint files at once, that saturates the metadata tier. | 21
- **Small-file problem** — The collapse in effective throughput when files are so small that per-file metadata operations, not bandwidth, limit performance. | 21
- **Subtree partitioning** — Scaling metadata by assigning whole directory subtrees to different metadata servers, statically or dynamically. | 21
- **Hashed (striped) directory** — A directory whose entries are spread across several metadata servers by hashing names. | 21
- **Distributed Namespace (DNE)** — Lustre's feature for spreading the namespace over multiple metadata targets, via remote directories and striped directories. | 21
- **Data-on-MDT (DoM)** — A Lustre layout that stores small files, or the start of larger files, on the metadata target to avoid extra round trips. | 21
- **Log-structured design** — A storage design that appends every change to a log and garbage-collects old versions instead of updating in place. | 21
- **FoundationDB** — An open-source distributed transactional key-value database used as the metadata store by systems such as DeepSeek's 3FS and Snowflake. | 21
- **WebDataset** — A data-loading format and library that packs training samples into large tar shards so they can be read sequentially. | 21
- **mdtest** — The metadata benchmark used in IO500, measuring create, stat, read and delete rates in private (easy) and shared (hard) directories. | 21
