- **Control plane** — The part of a storage system that holds desired state (volumes, policies, placement) and configures the data plane, operating in seconds rather than microseconds. | 22
- **Data plane** — The I/O path of a storage system that actually moves and protects bytes, which must keep running even if management services are unreachable. | 22
- **Management plane** — A fleet-wide layer, often vendor-hosted in the cloud, that aggregates many arrays' control planes for monitoring, analytics and policy. | 22
- **Phone-home telemetry** — Outbound metrics, logs and health data that an array sends to its vendor's cloud for support and analytics. | 22
- **AIOps** — Use of analytics and machine learning on infrastructure telemetry to predict faults, open tickets and recommend or take corrective actions. | 22
- **Issue fingerprint** — A telemetry signature of a known fault that a vendor matches across its connected fleet to prevent recurrences. | 22
- **Dark site** — A customer installation that does not phone home, typically for security reasons, and therefore forgoes cloud analytics. | 22
- **Storage as code** — Declaring storage resources and policies in version-controlled automation (Terraform, Ansible, Kubernetes manifests) instead of configuring them by hand. | 22
- **Infrastructure as code (IaC)** — Managing infrastructure through declarative, version-controlled definitions applied by tools such as Terraform or Ansible. | 22
- **CSI (Container Storage Interface)** — The standard plug-in interface through which Kubernetes asks a storage system to create, attach and delete volumes. | 22
- **StorageClass** — A Kubernetes object naming a class of storage (performance, protection) that persistent volume claims request by name. | 22
- **Preset (Pure Fusion)** — A fleet-wide template bundling capacity, QoS, protection and tags that Fusion uses to provision a workload consistently. | 22
- **Pure Fusion** — Everpure's policy-driven fleet control plane, embedded in Purity, that provisions workloads across FlashArray, FlashBlade and cloud arrays. | 22
- **Pure1** — Everpure's SaaS monitoring, analytics and support portal fed by array phone-home telemetry. | 22
- **MCP (Model Context Protocol)** — An open protocol that lets AI agents connect to tools and data sources, now exposed by several storage management planes. | 22
