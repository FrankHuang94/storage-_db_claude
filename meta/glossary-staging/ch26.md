- **Purity** — Everpure's storage operating system for FlashArray (Purity//FA) and FlashBlade (Purity//FB), built as a log-structured, metadata-centric design. | 26
- **DirectFlash** — Everpure's approach of letting Purity manage raw NAND directly instead of going through each SSD's own controller and FTL. | 26
- **DirectFlash Module (DFM)** — Everpure's proprietary flash module that exposes raw NAND through a thin controller, with no drive-level flash translation layer. | 26
- **Global FTL** — a single flash translation layer that maps, garbage-collects and wear-levels across every flash module in an array rather than inside each drive. | 26
- **Log-on-log** — stacking one log-structured layer (such as an array) on another (such as an SSD FTL), so their garbage collection and write amplification compound. | 26
- **RAID-HA** — Purity's dual-parity data protection scheme across flash modules. | 26
- **Metadata pyramid** — Everpure's term for Purity's tiered metadata store, with hot entries in DRAM, in-flight changes in NVRAM and the bulk on flash. | 26
- **Monotonic write** — a write that only ever appends new data or records and never modifies existing ones in place. | 26
- **Indirection unit** — the granularity at which an SSD's mapping table tracks data; larger units save DRAM but penalise small random writes. | 26
- **Hidden over-provisioning** — NAND capacity inside an SSD reserved for garbage collection and wear that the host can neither see nor use. | 26
- **NAND qualification** — characterising a new NAND die (read thresholds, retention, program timing) so firmware or software can drive it reliably. | 26
- **Integrated memory controller** — a DRAM controller built onto the CPU die instead of a separate northbridge chip; the analogy for moving flash control into array software. | 26
- **Open-channel SSD** — an SSD that exposes NAND geometry to the host so host software performs flash management, the precursor of zoned and placement-hint designs. | 26
- **DirectFlash licence** — Everpure's hyperscaler model in which the customer licenses DirectFlash software and design and sources its own NAND and hardware. | 26
- **IBM FlashCore Module** — IBM's proprietary flash module for FlashSystem that keeps an in-module FTL and adds compression, encryption and threat detection. | 26
