- **Everpure Platform** — Everpure's name for its whole software and hardware stack (Purity, arrays, Fusion, Pure1, Portworx, Everpure Cloud, Data Intelligence) sold as one platform. | 28
- **Enterprise Data Cloud (EDC)** — Architecture launched by Pure Storage in June 2025 that presents all of a customer's arrays and cloud storage as one policy-driven pool managed through Fusion. | 28
- **Data Primacy** — Everpure's 2026 strategic framing that puts trusted, classified data rather than applications at the centre of the infrastructure stack. | 28
- **Evergreen//Forever** — Everpure subscription for customer-owned arrays that includes non-disruptive controller refreshes tied to renewals, subject to program terms. | 28
- **Evergreen//Flex** — Everpure model in which the customer owns the arrays but pays for capacity used, pooled across the fleet. | 28
- **Evergreen//One** — Everpure storage-as-a-service: Everpure owns the hardware and the customer pays per unit of used capacity under guaranteed SLAs. | 28
- **Capacity buffer** — Spare capacity a storage-as-a-service vendor guarantees to keep installed above the customer's current use (25% for Evergreen//One). | 28
- **Fusion preset** — A named, fleet-wide template in Everpure Fusion that bundles performance limits, protection policy and tags for provisioning workloads. | 28
- **Portworx** — Everpure's software-defined data-services layer that gives Kubernetes containers and VMs persistent storage, replication, backup and DR on any infrastructure. | 28
- **KubeVirt** — Open-source project that runs virtual machines as Kubernetes objects, a common VMware-exit path. | 28
- **Everpure Cloud Dedicated** — Customer-managed Purity running in the customer's own AWS or Azure account; formerly Cloud Block Store. | 28
- **Everpure Cloud Azure Native** — Fully managed Everpure block storage delivered as an Azure Native ISV service, co-developed with Microsoft. | 28
- **Everpure Data Intelligence** — Everpure's data discovery, classification and governance product built on the 1touch acquisition. | 28
- **Data Stream** — Everpure's GPU-accelerated pipeline on FlashBlade that ingests, indexes and vectorises data for AI, based on NVIDIA's AI Data Platform design. | 28
- **Attach rate** — The share of an installed customer base that buys an additional product. | 28
- **Net dollar retention (NDR)** — This year's recurring revenue from last year's customer cohort divided by that cohort's revenue a year earlier. | 28
- **MCP server** — A service that exposes tools and data to AI agents through the Model Context Protocol, here used to let agents query and act on storage fleets. | 28
