- **DGX BasePOD** — NVIDIA's reference architecture for enterprise GPU clusters of two to dozens of DGX systems, with a list of validated storage partners. | 34
- **DGX SuperPOD** — NVIDIA's turnkey large-cluster reference architecture, built from scalable units, with storage certified against per-generation performance tables. | 34
- **Scalable unit (SU)** — The 32-node building block of a DGX SuperPOD (256 GPUs with eight-GPU nodes). | 34
- **NVIDIA Cloud Partner (NCP)** — NVIDIA's program and reference architectures for GPU cloud providers, including storage uptime, durability and delivery requirements. | 34
- **High-performance storage (HPS) certification** — NVIDIA's certification that a storage system meets the NCP reference architecture's fast-storage tier. | 34
- **NVIDIA-Certified Storage (NVCS)** — NVIDIA's tiered storage certification program (Foundation, Enterprise, NCP levels) launched in March 2025. | 34
- **Foundation level** — The entry NVIDIA-Certified Storage tier, testing workloads that simulate up to 128 GPUs. | 34
- **Enterprise level** — The middle NVIDIA-Certified Storage tier, simulating workloads of about 1,000 GPUs. | 34
- **NVIDIA AI Data Platform** — NVIDIA's 2025 reference design for putting GPUs, DPUs and NVIDIA retrieval software inside storage systems. | 34
- **AI-Q blueprint** — NVIDIA's reference agent workflow that uses NeMo Retriever microservices to search enterprise data. | 34
- **NeMo Retriever** — NVIDIA microservices that extract, embed and rerank enterprise data for retrieval-augmented generation. | 34
- **NIM** — NVIDIA Inference Microservices, packaged containers that serve AI models behind standard APIs. | 34
- **BlueField-4 STX** — NVIDIA's 2026 modular storage reference architecture built on Vera Rubin, BlueField-4 DPUs and Spectrum-X networking. | 34
- **CMX** — NVIDIA's context memory storage platform, the first rack-scale STX implementation, used as a KV-cache tier. | 34
- **Inference Context Memory Storage (ICMS)** — NVIDIA's CES 2026 name for its BlueField-4-powered KV-cache storage tier, later delivered as CMX. | 34
- **Approved vendor list (AVL)** — A platform owner's list of qualified component suppliers that reference designs may use. | 34
