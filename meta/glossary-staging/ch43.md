- **NeuralMesh** — WEKA's software-defined storage platform since June 2025, the re-architected successor to WekaFS and the WEKA Data Platform. | 43
- **NeuralMesh Axon** — WEKA's packaging of NeuralMesh to run inside GPU servers on their local NVMe drives and spare CPU cores. | 43
- **NeuralMesh 6** — WEKA's July 2026 platform release adding multi-tenancy, always-on data reduction and native object access. | 43
- **WekaFS** — WEKA's original parallel, POSIX-compliant file system for NVMe flash with tiering to object storage. | 43
- **Augmented Memory Grid (AMG)** — WEKA's KV-cache offload tier that stores evicted attention key/value blocks on pooled NVMe and streams them back to GPUs. | 43
- **Token warehouse** — WEKA's marketing term for the pooled NVMe store that holds KV-cache blocks for reuse across GPU servers. | 43
- **Converged mode** — A deployment in which storage software runs on the same servers as the applications or GPUs, using their local drives. | 43
- **Dedicated mode** — A deployment in which storage software runs on separate storage servers rather than on the compute nodes. | 43
- **DPDK (Data Plane Development Kit)** — A user-space networking library that lets software drive a NIC directly, bypassing the operating-system network stack. | 43
- **SPDK (Storage Performance Development Kit)** — A user-space library for driving NVMe devices directly with polling instead of kernel interrupts. | 43
- **Kernel bypass** — Handling network or storage I/O in user space so requests avoid system calls, interrupts and kernel copies. | 43
- **Busy polling** — Having a dedicated CPU core repeatedly check for completed I/O instead of waiting for an interrupt, trading CPU for lower, steadier latency. | 43
- **Metadata bucket** — In WEKA, one of thousands of hashed shards of the file-system namespace, each owned by a virtual metadata server. | 43
- **Virtual metadata server** — A software metadata owner running inside WEKA's compute processes on every node, replacing a dedicated metadata server. | 43
- **WEKApod** — WEKA's branded storage appliance line; WEKApod 3 (2026) offers Nitro, Prime and Prime Max configurations. | 43
- **NIXL (NVIDIA Inference Xfer Library)** — NVIDIA's open-source library for moving KV-cache data between GPU memory, host memory and storage. | 43
- **NVIDIA STX** — NVIDIA's BlueField-4-based storage reference architecture launched at GTC 2026. | 43
- **CMX** — NVIDIA's context-memory storage platform, the first rack-scale implementation of STX, holding KV cache between GPU servers and shared storage. | 43
- **Effective capacity** — Usable capacity multiplied by an assumed data-reduction ratio, so it depends on how compressible the data is. | 43
