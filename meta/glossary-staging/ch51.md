- **DASD (direct-access storage device)** — IBM's term for mainframe disk storage, as opposed to sequential tape. | 51
- **RAMAC** — IBM's 1956 305 computer and its 350 disk unit, the first commercial hard disk system (about 3.75 MB). | 51
- **SLED (single large expensive disk)** — The RAID paper's name for the big mainframe drives that arrays of small disks replaced. | 51
- **RAID (redundant array of inexpensive disks)** — Combining many cheap drives with mirroring or parity so the group is faster and more reliable than any one drive. | 51
- **Cached disk array** — A storage array that fronts many commodity disks with a large RAM cache so most I/O never waits for a disk (EMC Symmetrix, 1990). | 51
- **Filer** — A dedicated network file-server appliance that does nothing but serve files over NFS or SMB (NetApp's original product). | 51
- **SAN (storage area network)** — A dedicated network, originally Fibre Channel, that lets many servers share block storage arrays. | 51
- **Scale-out NAS** — A file system spread across a cluster of nodes behind one namespace, grown by adding nodes rather than upgrading controllers. | 51
- **HCI (hyperconverged infrastructure)** — Running storage software on the same servers as the virtual machines, pooling their local drives. | 51
- **Architectural pendulum** — The recurring swing of storage design between centralized pools, distributed nodes and disaggregated fabrics as media, network and CPU costs change. | 51
- **Software-defined wave** — A period when storage functions move from proprietary controllers onto commodity servers as software. | 51
- **Forklift upgrade** — Replacing an entire storage system, with data migration, at the end of its life; the refresh model Evergreen-style subscriptions attack. | 51
- **MLPerf Storage** — The MLCommons benchmark, first run in 2023, that scores how many simulated accelerators a storage system can keep busy. | 51
