- **Latency adder** — The extra time per I/O that a transport or software layer adds on top of the storage device itself. | 60
- **Partitioned-writer** — Everpure's term for the FlashBlade design in which blades own slices of the namespace while flash is managed globally. | 60
- **Metadata/data split** — A design in which clients get a file layout from metadata servers and then move data directly to and from data servers. | 60
- **Single-mount ceiling** — The throughput one client mount can reach before extra connections or parallel paths are needed. | 60
- **Stock client** — The protocol client built into the operating system, as opposed to a vendor-supplied kernel module or agent. | 60
- **Proprietary parallel client** — A vendor kernel module or agent that stripes I/O directly across storage servers, as in Lustre, IBM Storage Scale or WEKA. | 60
- **Command set vs. transport** — The split between what a storage protocol says (SCSI or NVMe commands) and how it travels (PCIe, FC, RDMA or TCP). | 60
- **Protocol family** — The three ways a host sees storage: as a disk (block), a directory tree (file) or a bucket of keys (object). | 60
- **Cloud block storage** — Hyperscaler-run software-defined block volumes such as AWS EBS, the seventh row of the atlas's architecture matrix. | 60
